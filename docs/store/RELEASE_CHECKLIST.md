## 2. Release Engineering & Cryptographic Signing

- [x] **Gradle Signing Configuration**:
  - Script: `scripts/build-android-release.mjs`.
  - Config: `android/app/build.gradle` reads keystore credentials from environment variables (`APEX_RELEASE_KEYSTORE_PATH`, `APEX_RELEASE_KEYSTORE_PASSWORD`, `APEX_RELEASE_KEY_ALIAS`, `APEX_RELEASE_KEY_PASSWORD`).
  - Safe fallback: If environment variables are absent, Gradle builds unsigned release AAB without crashing.
- [x] **Play App Signing**:
  - Keystore generated by the owner is kept offline and never committed to git.
  - Google Play App Signing will re-sign the app with Google's release key for Play distribution.
- [x] **Security Invariants**:
  - `minifyEnabled true` and `shrinkResources true` enabled in release build type.
  - Proguard keep rules protect Capacitor plugins (`com.capacitorjs.**`, `com.getcapacitor.**`).
  - `usesCleartextTraffic false` with restrictive `network_security_config.xml` (TLS only).
  - WebView debugging explicitly disabled in release builds.
  - Zero background location permissions in `AndroidManifest.xml`.

## 5. Deployment Stages Progression

1. **Step 1: Internal Testing Track**:
   - Upload signed AAB.
   - Internal team verifies install, camera capture, GPS locking, and sign-out/sign-in.
2. **Step 2: Closed Testing Track (20 Testers / 14 Days)**:
   - Invite 20+ testers via Google Group or email list.
   - Ensure all 20 testers download and open the build within the 14-day window.
   - Monitor crash reporting (`src/services/crashReporter.ts`).
3. **Step 3: Production Release Application**:
   - Answer the 20-tester questionnaire in Google Play Console.
   - Request production access.
   - On approval: roll out to production with staged percentage (e.g. 10% $\rightarrow$ 25% $\rightarrow$ 50% $\rightarrow$ 100%).
